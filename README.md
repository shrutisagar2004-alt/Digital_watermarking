Image Watermarking Tool using MATLAB

A MATLAB-based application that adds customizable text watermarks to images. Users can select an image, enter watermark text, choose from multiple watermark positions (including diagonal), and generate a translucent watermarked image while preserving image quality.

Features
Add custom text watermark to any image
Six watermark placement options:
Top Left
Top Right
Bottom Left
Bottom Right
Center
Diagonal Center
Adjustable watermark transparency
Supports JPG, PNG, and BMP image formats
Saves the final watermarked image automatically
Technologies Used
MATLAB
Image Processing Toolbox
Workflow
Select an input image.
Enter the watermark text.
Choose the watermark position.
Apply a translucent watermark.
Preview and save the final watermarked image.
